# AAA.AMBULANCE3 desktop releases

Installers for the AAA.AMBULANCE3 desktop app (macOS and Windows), published as GitHub Releases.

This repository holds release files only: there is no source code here. Installed apps find new
versions through their update feed and download the installer from the matching release below.

To install for the first time, open the latest release and download:

- **Mac:** `AAA-Ambulance3-<version>-mac-universal.dmg`
- **Windows:** `AAA-Ambulance3-<version>-win-x64-setup.exe`
